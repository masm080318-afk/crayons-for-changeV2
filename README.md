# Crayons for Change

The current website is the static index.html at the repository root, with styles.css, site.js, content.js, and images/.

GitHub Pages publishes the root of main to https://crayons4change.org/. Preserve CNAME, .nojekyll, and .well-known/.

Edit content.js to add approved program URLs and photos. Donation links use the supplied Zeffy form. The homepage contains the youth-led mission, 700+ supplies distributed, Ahmedabad and Philippines projects, and completed community events.

Run npm run check to verify asset references, section anchors, photos, and domain. npm run build performs the same validation; no generation is needed. The previous generator and data remain as historical source but are no longer invoked by the build command.

Previous page URLs redirect to matching sections of the new homepage. The repository belongs to masm080318-afk; updates are contributed using abhim65.
